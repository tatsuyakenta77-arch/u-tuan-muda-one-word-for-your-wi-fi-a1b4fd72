One word that describes my Wi-Fi: **Gaslighting** — the router insists
everything is fine ("Connected, no internet") while nothing loads. It is the
most familiar home Wi-Fi experience there is: the signal is full, the pages
never arrive, and somehow it is always your fault.

The program writes that single word to `/output/entry.txt`. One word, 11
characters, deterministic — the same bytes on every run.

## Run it

```sh
python3 main.py
```

This writes `Gaslighting` (no trailing newline) to `/output/entry.txt`.
Set `ENTRY_OUTPUT_DIR` to write somewhere else when testing locally.
